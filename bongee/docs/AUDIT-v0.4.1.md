# v0.4.1 기능 감사와 성능 확인

2026-10-09, v0.4.0 배포본 점검 후 보완.

## 판정

기본 협업·격리·메시지·진행판 기능은 검사에 통과했다. 시작 실패 보고 재시도 누락은 새 테스트로 재현해 수정했다. 모든 431개 도구의 외부 서비스 기능이나 실제 LLM 자율 작업 완료를 검증한 것은 아니다.

- 기존 전체 회귀129개 통과. 신규 장애/성능 회귀 포함132개 통과. 버전 변경 후 설치·두 MCP 통신6개 추가 확인.
- 시작 실패도 lease와 실패 결과를 보존하고 통신 복구 시 재전송. 해당 작업을 다시 실행하지 않음.
- 조회는 atomic rename으로 저장 완료된 스냅샷을 읽고, 전체 저장소 쓰기와 쓰기 잠금 대기를 생략. 권한·소유자·심볼릭 링크 검사는 유지.
- 전체 도구 목록은 최초·30초 간격·서버 재요청 때 전달하며 heartbeat는 유지.

## 남은 제한

- 원격 실행은2초 폴링 및 순차claim으로 병렬 요청이 대기한다. 로컬 조회 개선율을 전체 원격 지연 개선율로 주장하지 않는다.
- 프록시 재시작 시 새 endpoint ID. 과거 미확인 메시지는 파일에 남지만 새 수신함으로 자동 복구되지 않음. 상대 수신 확인이 필요.
- 저장 한도: 메시지2000건, endpoint1024개, endpoint당100개 보고,20MB. 누적 기록 자동 정리·복구 UI 없음.
- 쓰기/10초 heartbeat는 전체 JSON 저장 구조를 유지한다. 장기간 다수 사용자 부하는 별도 저장소 개선 필요.
- 초기 도구/세션 연결 실패 뒤 원인 해소만으로 자동 재연결되지 않을 수 있어 실행기 재시작 필요.
- 외부 BATON 방 생성·전송, 유료 모델 생성·실제 개발 파이프라인은 이번 점검에서 실행하지 않음.

근거: bongee/output/audit-v0.4.0/의 회귀 로그·측정 JSON·재현 스크립트.
